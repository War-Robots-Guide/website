# Supplemental module artwork

The Drive library lacks several module images. These checked-in files live in
`public/module-images/` so rebuilding the generated `public/images/` mirror
does not delete them. Exact module lookups prefer an image supplied by the
library when that exact name is available, then use these supplements.

Artwork is War Robots game artwork, retrieved from the community
[War Robots Wiki module catalog](https://warrobots.wiki/info/modules).
